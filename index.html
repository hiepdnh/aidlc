Why ADLC

Built for how AI-assisted
teams actually work

Structured commands, multi-agent delegation, and human decision gates — so your team stays in control while AI handles the heavy lifting.

Multi-Agent Pattern

Heavy tasks spawn specialized lightweight subagents (haiku for parsing, sonnet for synthesis), keeping your main context window clean and focused.

Human-in-the-Loop Gates

Every command includes mandatory decision gates — Claude presents options and waits for your approval. No autonomous auto-execution ever.

Two-Tier Documentation

Ephemeral per-task docs (gitignored) for in-progress work, plus living baseline docs updated after each verified merge. Always-current knowledge.

Developer Lite Option

A minimal subset for teams that need only core developer workflow — without PM/BA/QA/Ops overhead. 8 focused commands to get started fast.

Security-First Review

Built-in OWASP Top 10 security review command with Always/Ask/Never classification. Security baked into the workflow, not bolted on.

Full SDLC Coverage

From ideation to deployment — BA, PM, Dev, Arch, QA, DevOps, Security, Docs, and Scrum roles all covered in one cohesive framework.

Subagent Architecture

Agent Used by Model Purpose

Get Started

Install in seconds

Drop into any project. Works with Claude Code CLI. No build step required.

macOS / Linux

Full install — all 26 commands

npx github:hiepdnh/Agentic-Development-Lifecycle --yes
Installs: .claude/commands/ · agents/ · templates/ · docs/workflows/

Windows

PowerShell install

# PowerShell
$tmp = "$env:TEMP\vti-install"
mkdir $tmp -Force; Set-Location $tmp
npx github:hiepdnh/Agentic-Development-Lifecycle --yes
Or use setup.ps1 from the repo for a streamlined Windows experience.
